## Report a vulnerability

Report suspected vulnerabilities privately through
[SECURITY REPORTING CHANNEL]. Do not open a public issue or discussion.

Include the following information when possible:

* A description of the vulnerability and its potential impact
* Affected versions, configurations, or components
* Steps to reproduce or a proof of concept
* Known mitigations or workarounds
* A preferred contact method for follow-up

The security team will acknowledge the report within [ACKNOWLEDGMENT WINDOW]
and provide an initial assessment within [ASSESSMENT WINDOW]. The team will
coordinate remediation and disclosure with the reporter. Public disclosure
should wait until a fix or mitigation is available unless earlier disclosure
is necessary to protect users.

## Security update process

The project publishes security updates through [SECURITY ADVISORY CHANNEL].
Maintainers will document affected versions, available fixes, and required user
actions in each advisory.
